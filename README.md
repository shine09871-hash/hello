## 인스타 콘텐츠 작업 순서

```
/ig-viral  →  /ig-plan  →  /ig-reel  →  /ig-caption  →  내가 확인하고 올리기
  조사          계획          대본          캡션
```

| 단계 | 명령 | 하는 일 | 만들어지는 파일 |
|------|------|---------|-----------------|
| 1 | `/ig-viral` | 요즘 반응 좋은 주제·형식·훅을 웹에서 조사 | `01-research.md` |
| 2 | `/ig-plan` | 주제 하나로 메시지·장면 흐름·찍을 것 정리 | `02-plan.md` |
| 3 | `/ig-reel` | 초 단위 대본 (말·화면 글자·효과음) | `03-reel.md` |
| 4 | `/ig-caption` | 캡션 2안·해시태그·올리기 전 점검표 | `04-caption.md` |
| 5 | (직접) | 점검표 확인 후 인스타 앱에서 게시 | — |

- 파일은 `ig/content/<날짜>-<주제>/` 폴더에 쌓인다.
- 처음 한 번 `ig/account.md`(계정 주제·말투·해시태그)를 채워 두면 모든 단계가 그것을 따른다.
- Claude는 인스타그램에 로그인하거나 게시하지 않는다. 조사는 웹 검색 기반이며, 확인 못 한 숫자·사실은 "확인 필요"로 표시한다.
