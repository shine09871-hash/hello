# 인스타 릴스 만들기

사용자가 올린 사진·영상으로 1080×1920 릴스 mp4와 커버 jpg를 만든다. 프로그램은 `scripts/make_reel.py`, 글꼴은 `scripts/fonts/`(Pretendard).

## 기본값 (사용자가 고른 것)
- **style: bold** — 큰 흰 글씨를 화면 가운데에 둔다. 사용자가 다른 스타일을 말할 때만 바꾼다.
  - magazine: 작은 글씨 왼쪽 아래 / vlog: 자막 없이 빠른 전환, 끝에만 정보
- 배경음악 없음. 사용자가 음악 파일을 주면 폴더에 넣는다. 인스타 앱에서 음악을 고르도록 안내한다(저작권).

## 순서
1. 준비: `pip install pillow numpy pyyaml pillow-heif` (이미 있으면 생략). `ffmpeg -version` 이 안 되면 `pip install imageio-ffmpeg` (프로그램이 알아서 찾음). ffprobe 는 없어도 된다.
2. 작업 폴더를 만들고 사용자 사진·영상을 순서대로 `01.jpg, 02.jpg, 03.mp4 …` 이름으로 복사한다. 첫 번째가 제목 화면이 되므로 가장 대표적인 사진을 01로.
3. 사진을 직접 보고 `reel.yaml` 을 쓴다 (아래 예시).
4. 실행: `python scripts/make_reel.py <폴더>` → `<폴더>/<폴더이름>_reel.mp4`, `_reel_cover.jpg`
5. 결과 영상에서 2~3장면을 캡처(`ffmpeg -ss 2 -i 결과.mp4 -frames:v 1 x.png`)해 글씨가 음식·얼굴을 가리거나 잘리지 않았는지 직접 본 뒤 전달한다. 영상과 커버를 사용자가 받을 수 있는 출력 폴더에 저장해 준다.

## 글 쓰기 규칙
- 사용자가 말하지 않은 사실(가격, 영업시간, 주소 번지, 맛 평가, 가게 이름)은 지어내지 않는다. 모르면 빼고, 끝에 "가게 이름·주소 알려주시면 넣을게요"처럼 묻는다.
- 자막은 짧게: 한 장면 한 줄, 12자 안팎. 이모지는 글꼴에 없어 자동 삭제되므로 쓰지 않는다.
- theme: food(맛집) / info(정보, 자막에 01·02 번호) / kids(아이와 가볼 곳) / book(책). 제목 위 작은 글씨와 마지막 문구만 바뀐다.

## 사진이 적을 때 (1~3장)
한 사진의 부분을 잘라 확대한 장면을 추가한다: `crop: [왼쪽, 위, 오른쪽, 아래]` (0~1 비율, 회전 보정된 사진 기준). 음식이면 고기·소스·채소처럼 눈에 띄는 부분마다 하나씩. 너무 작게 자르면 흐려지므로 가로 폭 0.4 이상. 사용자에게 "사진이 많을수록 깔끔하다"고 알린다.

## reel.yaml 예시
```yaml
theme: food
style: bold
title: "귀산동 스테이크"
subtitle: "무쇠팬 그대로 나오는 한 판"
handle: ""              # 사용자가 아이디를 알려주면 "@아이디"
clips:
  - file: 01.jpg        # 제목 화면 (자막 안 나옴)
  - file: 01.jpg
    crop: [0.0, 0.15, 0.45, 0.72]
    text: "두툼하게 구운 고기"
  - file: 02.mp4
    start: 1            # 영상 시작 지점(초)
    duration: 4         # 쓸 길이(초), 기본 최대 5초
    text: "소스와 콘치즈까지"
    sound: true         # 영상 원래 소리 (음악 없으면 기본 켜짐)
outro:                  # 끝 화면. 필요 없으면 outro: false
  name: "귀산동 스테이크"
  details:              # 아는 것만
    위치: "창원 귀산동"
  # cta: "저장해두고 꼭 가보세요"   (생략하면 theme 기본 문구)
```
길이 기본값(bold): 사진 2.6초, 제목 3초, 끝 화면 3.4초. 전체 10~20초가 적당하다. `duration` 으로 장면별 조절.
