# /ig-reel — 3단계: 대본

결과: 같은 폴더의 `03-reel.md`

## 먼저
1. `ig/account.md`와 해당 폴더의 `02-plan.md`를 읽는다. 없으면 /ig-plan을 먼저 하자고 말한다.
2. 말투·목소리 방식(내 목소리/글자만/AI 목소리)은 account.md를 따른다.

## 쓰는 규칙
- **첫 3초**: 질문, 놀라운 사실, 결과 먼저 보여주기 중 하나. 인사("안녕하세요")로 시작하지 않는다.
- **말 속도**: 한국어는 1초에 약 4~5글자로 잡고, 각 줄의 글자 수로 시간을 맞춘다. 합계가 계획한 길이를 넘으면 줄인다.
- **화면 글자**: 한 화면에 한 줄, 14자 안팎. 소리 없이 봐도 이해되게 쓴다.
- **문장**: 짧게. 한 문장에 정보 하나.
- **사실**: 02-plan.md의 "확인할 사실" 중 확인 안 된 것은 대본에 `[확인 필요]`로 표시해 둔다. 지어내서 채우지 않는다.
- **마무리**: 계획에서 정한 행동 유도 하나만.

## 03-reel.md 형식
```
# 대본: <제목>  (총 약 N초)

| 시간 | 장면(무엇을 찍은 화면) | 말할 문장 | 화면 글자 | 효과음·음악 |
|------|------------------------|-----------|-----------|-------------|
| 0~3초 | | | | |

## 훅 다른 버전 (2개)
1.
2.

## [확인 필요] 목록
- ...
```

## 끝
저장 후 대본 표를 보여준다. 사용자가 영상까지 만들고 싶어 하면 insta-reels 스킬(사진·영상 → 9:16 mp4)이나 create-typecast-shorts 스킬로 이어갈 수 있다고 알려준다. 아니면 /ig-caption으로 넘어간다.
