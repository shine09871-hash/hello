# /ig-caption — 4단계: 캡션

결과: 같은 폴더의 `04-caption.md`

## 먼저
1. `ig/account.md`, `02-plan.md`, `03-reel.md`를 읽는다. 03-reel.md가 없으면 /ig-reel을 먼저 하자고 말한다.
2. 인스타 캡션·해시태그 규칙(글자 수 제한, 해시태그 개수 제한)은 바뀔 수 있으므로 웹 검색으로 최신 공식 안내·보도를 한 번 확인하고, 확인한 내용과 출처를 04-caption.md에 적는다. 확인하지 못하면 "확인 못 함"이라고 적는다.

## 쓰는 규칙
- **첫 줄(약 125자 이전에 '더 보기'로 잘림)**: 릴스 훅과 이어지는 한 문장. 핵심을 여기 넣는다.
- **본문**: 대본의 정보를 저장할 만하게 정리 (목록, 주소·시간 등). `[확인 필요]`는 그대로 남겨 사용자가 보게 한다.
- **행동 유도**: 대본과 같은 것 하나.
- **해시태그**: account.md의 자주 쓰는 태그 + 이번 주제 태그. 확인한 개수 제한 안에서 고른다. 너무 넓은 태그만 쓰지 말고 지역·세부 주제 태그를 섞는다.
- **협찬·광고**: 협찬이 있으면 account.md 방식대로 표시한다. 있는지 모르면 묻는다.
- 캡션 2가지 버전(짧은 것 / 정보 많은 것)을 쓴다.

## 04-caption.md 형식
```
# 캡션: <제목>

## A안 (짧게)
...

## B안 (정보 많이)
...

## 해시태그
#...

## 확인한 인스타 규칙
- 내용 — 출처 / 또는 확인 못 함

## 올리기 전 점검표 (사용자가 직접)
- [ ] 영상 속 사실(가격·시간·주소·날짜) 다시 확인
- [ ] [확인 필요] 표시 모두 지움
- [ ] 화면 글자 오타
- [ ] 음악 저작권 (인스타 앱 안 음악 쓰기 권장)
- [ ] 사람 얼굴·아이 얼굴·차 번호판 노출 괜찮은지
- [ ] 협찬 표시
- [ ] 표지(커버) 이미지 고르기
- [ ] 위치 태그
```
