# /ig-plan — 2단계: 계획

결과: 같은 폴더의 `02-plan.md`

## 먼저
1. `ig/account.md`와 가장 최근(또는 사용자가 말한) `ig/content/*/01-research.md`를 읽는다.
2. 사용자가 고른 주제 후보를 쓴다. 안 골랐으면 "내 계정과 맞는 정도"가 가장 높은 것을 제안하고 확인받는다.
3. 01-research.md가 없으면 /ig-viral을 먼저 하자고 말한다. 사용자가 주제를 바로 주면 조사 없이 진행해도 되지만, 그 경우 02-plan.md 맨 위에 "조사 단계 없이 진행"이라고 적는다.

## 정할 것
- **핵심 메시지 한 문장**: 보는 사람이 끝까지 보고 가져갈 것 하나
- **보는 사람이 얻는 것**: 정보 / 재미 / 공감 중 무엇
- **형식**: 조사에서 나온 형식 중 하나와 고른 이유
- **길이**: account.md 기준 (없으면 15~30초 제안)
- **장면 흐름**: 훅(0~3초) → 본론 → 마무리·행동 유도(저장, 공유, 댓글 중 하나만)
- **찍을 것 목록**: 장면마다 필요한 사진·영상. 사용자가 이미 가진 자료가 있는지 묻고, 없는 것만 "새로 찍기"로 표시
- **확인할 사실**: 가격, 영업시간, 주소, 날짜처럼 틀리면 안 되는 것. 출처가 없으면 "현장·공식 채널에서 확인 필요"로 둔다

## 02-plan.md 형식
```
# 계획: <제목>

- 핵심 메시지:
- 얻는 것:
- 형식: (이유)
- 길이:
- 행동 유도:

## 장면 흐름
| # | 시간 | 장면 | 화면에 나올 것 | 자료(있음/새로 찍기) |

## 찍을 것 체크리스트
- [ ] ...

## 확인할 사실
- [ ] 내용 — 출처 또는 "확인 필요"
```

## 끝
저장 후 장면 흐름 표를 보여주고, 바꿀 곳이 없으면 /ig-reel로 넘어가자고 말한다.
