# /ig-viral — 1단계: 조사

결과: `ig/content/<YYYY-MM-DD>-<짧은주제>/01-research.md`

## 먼저
1. `ig/account.md`를 읽는다. 주제·보는 사람이 비어 있으면 그것만 물어보고 채운 뒤 진행한다.
2. 사용자가 이번에 다룰 주제를 줬으면 그 주제로, 안 줬으면 계정 주제 전체로 조사한다.

## 할 수 없는 것 (사용자에게 숨기지 않는다)
- 인스타그램에 로그인하거나 앱 안의 실시간 인기 릴스·조회수를 직접 볼 수 없다.
- 그래서 조사는 웹 검색(뉴스, 트렌드 기사, 블로그, 공개 게시물 소개 글, 공식 발표)으로 한다.
- 숫자(조회수, 좋아요, 검색량)는 출처에 적힌 것만 쓰고 출처 주소를 붙인다. 출처가 없으면 "확인 못 함"이라고 쓴다. 지어내지 않는다.
- 사용자가 직접 본 인기 릴스 링크·캡처를 주면 그것을 가장 먼저 분석한다.

## 조사할 것
웹 검색은 한 번에 여러 개를 같이 보낸다. 오늘 날짜 기준 최근 1~3개월 자료를 우선한다.
1. **주제**: 이 분야에서 요즘 이야기되는 것 (계절, 행사, 새로 연 곳, 화제 소식)
2. **형식**: 잘 된다고 소개되는 릴스 형식 (예: 순위 3가지, 전후 비교, 하루 따라가기, 실패담)
3. **첫 1~3초 훅**: 실제 쓰인 첫 문장·첫 장면 예시
4. **인스타 변화**: 최근 알고리즘·기능 변경 공식 발표나 보도 (출처 필수)

## 01-research.md 형식
```
# 조사: <주제> (<날짜>)

## 한 줄 결론
이번에 하면 좋을 방향 한 줄

## 주제 후보 (3~5개)
| 후보 | 왜 지금인가 | 근거(출처) | 내 계정과 맞는 정도(상/중/하) |

## 잘 되는 형식
- 형식 — 설명 — 출처

## 훅 예시
- "첫 문장" — 어디서 봤는지

## 인스타 변화 (있을 때만)
- 내용 — 날짜 — 출처

## 확인 못 한 것
- 찾았지만 근거가 약하거나 숫자를 확인하지 못한 것
```

## 끝
파일을 저장하고, 사용자에게 주제 후보 표만 보여준 뒤 "어느 후보로 /ig-plan 할까요?"라고 묻는다.
